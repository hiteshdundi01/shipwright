# Debates

A change to the review contract (`template/docs/REVIEW_PROTOCOL.md`) or to the roster's roles is policy. It's debated first with the `debate` skill, and the outcome is recorded here, one file per debate: `<YYYY-MM-DD>-<slug>.md`, with its brief, each round's answer and the evidence beside it in a folder of the same name.

The skill says what a record holds: [`skills/debate/SKILL.md`](../../skills/debate/SKILL.md).
